# IronPulse Fitness - Multi-Page Gym Static Website (HTML5, CSS3, JavaScript)

A high-energy, bold fitness and gym website built with modern CSS custom properties, dynamic neon red & dark industrial themes, smooth scrolling, and structured folder layout (`css/`, `js/`, `assets/`). Ideal for practicing static site deployments on AWS S3, CloudFront, and CI/CD pipelines.

## 🚀 Pages Included
1. **Home (`index.html`)**: High-impact hero banner, training programs, and elite trainer highlights.
2. **Programs (`programs.html`)**: Detailed strength, cardio, and CrossFit workout programs with pricing tiers.
3. **Schedule (`schedule.html`)**: Interactive weekly gym class timetable and live slot indicators.
4. **Join / Contact (`contact.html`)**: Membership inquiry form with real-time validation and success alert.
